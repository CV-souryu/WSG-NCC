# 速度与内存（螺旋公共掩码 NCC，Apple M4，3052 张库）

| 指标 | 数值 |
|---|---:|
| 码本构建（首次） | ~5.5 s（3052 张：全包 / 圆心 0.5,0.25 / pitch 31.6 / 间距 2px / px 5×5 / pool 1 → 471 码点 / 264 公共） |
| 码本加载（缓存） | ~0.06 s |
| 纯匹配（全库打分 + Top-10 精算，不含解码） | ~0.55 ms |
| 端到端单查询（含解码+采样） | ~5–7 ms |
| 批量打分（剔除解码，µs/图） | 见下方「批量打分 CPU vs GPU」——CPU BLAS 全面快于 GPU（m≥100 时 CPU ~2 µs/图 vs GPU ~20 µs/图） |
| 匹配耗时（解码后：缩放+采样+打分+Top-10 精算，不含 png→numpy） | 螺旋 ~4–5 ms（1426/T2 = 3.97/5.02 ms）／同心圆 ~1.1–2.2 ms（1.12/2.16 ms，2×2 像素池化，采样量约 1/7） |
| 同心圆匹配组件（1426/T2，解码后） | 采样 0.99/2.04 ms（占 88–94%）＋ 粗筛 corr 0.015 ms（~1%）＋ Top-50 精算 0.11 ms；批量 m=100 时 corr+refine：CPU 91 µs/图 vs GPU 139 µs/图（CPU 仍快） |
| 解码（png→numpy，可按需剔除） | ~2.3–2.8 ms |
| 吞吐（每秒约张数） | CPU 端到端（含解码）~200 张/s；**剔除解码后** 螺旋 ~220 张/s、同心圆 ~610 张/s；
  批量打分（仅 NCC，m≥100）CPU ~60 万张/s、GPU ~5 万张/s；
  完整管线上限由解码+采样决定（除非批量/并行解码） |
| 码本内存 | 降级加载（float16，默认）~2.9 MB / 全精度（float32）~6.5 MB；10000 张降级约 9.4 MB |
| 磁盘缓存 | ~6.5 MB（默认 float32 全精度存储） |

### 批量打分 CPU vs GPU（剔除解码，µs/图，中位数）

| 批量 m | 螺旋 CPU | 螺旋 GPU | 同心圆 CPU | 同心圆 GPU |
|---|---:|---:|---:|---:|
| 1 | 8 | 253 | 15 | 366 |
| 10 | 2.5 | 39 | 27 | 58 |
| 100 | **1.6** | 18 | **2.7** | 27 |
| 500 | **2.2** | 17 | **2.6** | 24 |

两个码本的批量打分 CPU 都比 GPU 快 ~10 倍。原因：K≈264–342 很小，码本
（~4–5 MB）全驻缓存，numpy 走 Accelerate BLAS 单次 sgemm；而 Metal 内核
`corr_dot` 每输出元素单线程算一个 K 点积，访存延迟受限，加 dispatch 固定
开销（0.25–0.37 ms），反而更慢。GPU 仅在码本/库极大（K、N 都远超缓存）
时才可能反超。完整管线（剔除解码）被 CPU 采样（~0.9–2 ms/图）主导，
GPU corr 优势无从发挥。

精度选项：
- `--precision float32|float16`：**磁盘存储精度**，默认 float32（全精度档案）；
- `--load-precision float16|float32`：**加载到内存的精度**，默认 float16（降级加载，
  Top-1 NCC 与全精度仅差 ~0.0001，内存省 2.3 倍）。

采样点与公共掩码：

| 采样点数 | 公共码点 | 纯粗筛 | 1426/T2 Top-1 |
|---|---:|---:|---|
| 默认：pitch31.6 + 间距2 + px5 + pool1 | 264（471 码点） | ~7 µs | 0.921 / 0.944 |
| 2048 + pool 4 | 419（512 码点） | ~10 µs | 0.949 / 0.939 |

公共掩码对背景占比大的测试图（如 T2，背景 ~19%）至关重要：
无掩码时 T2 第一名/第二名几乎并列（0.536/0.527），带掩码 0.933/0.610。

### 码点池化（4 合 1 / 9 合 1）

相邻码点分块平均后再匹配，平滑噪声、粗筛更快、内存更小，Top-1 不变：

| pool（默认 4） | 码点数 | 公共码点 | 纯粗筛 | 码本内存 | 1426/T2 Top-1 | 合成召回@10 |
|---|---:|---:|---:|---:|---|---:|
| 1 | 2048 | 1629 | 229 µs | 32.4 MB | 0.935 / 0.933 | 100/100 |
| 1 | 471（471 点，pitch31.6 / 间距2 / px5） | 264 | ~7 µs | 6.1 MB | 0.921 / 0.944 | 99/100 |
| 4 | 512（2048 点） | 419 | 10 µs | 12.9 MB | 0.949 / 0.939 | 99/100 |
| 9 | 227 | 193 | 5 µs | 5.8 MB | 0.967 / 0.954 | 99/100 |

用法：`python -m scripts.spiral_ncc data/queries/1426.png --pool 4`（默认 1）。
